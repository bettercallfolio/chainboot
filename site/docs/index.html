# docs

Documentation

Twelve short guides, written in plain language. Start with the first two; the rest can be read in any order.

  1. 01Getting startedInstall, add an endpoint, run your first system, notes for each platform.
  2. 02How it worksThe whole idea in plain words: files as transactions, images, machines.
  3. 03MachinesRunning, several terminals, keeping one up, services, exporting.
  4. 04Saving to chainWallet sign-in, the vault, encryption, automatic saves, restore, conflicts.
  5. 05Publishing your own systemPut any Linux distribution on chain: private by default, public when you say so.
  6. 06The SDKStore files, move pointers, pool endpoints, encrypt for a wallet: with examples.
  7. 07The on-chain formatEvery byte chainboot writes, so anyone can build a reader or writer.
  8. 08Networks and costsDevnet, testnet, mainnet; what storing data costs; how long it stays.
  9. 09SecurityWhat you trust, what you do not have to, and where the limits are.
  10. 10Ideas and roadmapWhat else can be built with these parts, and what comes next.
  11. 11Questions and problemsCommon questions and what to do when something goes wrong.
  12. 12Thank youThe people and projects chainboot stands on.
