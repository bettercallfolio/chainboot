# chainboot website

A static page: `index.html`, `style.css`, `app.js`, `favicon.svg`. No build step, no
dependencies, no outside requests. Open `index.html` in a browser, or serve this folder with
any web server:

```sh
npx serve site        # or: python3 -m http.server -d site 8080
```

It can be hosted as it is on GitHub Pages, Vercel, Netlify, Cloudflare Pages or any file server.
