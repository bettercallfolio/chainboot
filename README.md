# chainboot

**Store, share and boot whole operating systems from a blockchain.**

chainboot puts a complete Linux system on the Solana ledger and starts it on your own
computer, in your own terminal, at full native speed. No server sits in between: the
program reads the chain directly through the RPC endpoints you give it and verifies every
byte before it is used.

The example system is **Solbuntu**: Ubuntu 26.04 LTS on Solana. The tool itself is
universal: any Linux distribution, and in fact any file, can be published the same way.

> Status: early development. Devnet only for now. Full documentation is being written in `docs/`.
