chainboot git

A git repository, read from Solana

This page finds a repository on the chain, fetches its packs and checks them: the list of branches by its owner's signature, everything else by SHA-256. It talks only to the RPC endpoints named below.

The public devnet endpoint is free and slow. An endpoint of your own (many providers have a free plan) is much faster; they are kept in this browser only.

Files Commits Issues and pull requests

Everything shown here was written by the repository's owner and by other people: names, texts and files are untrusted and are shown as text only. Writing an issue or a comment sends one small transaction from your own wallet, on the network of the endpoints above.
