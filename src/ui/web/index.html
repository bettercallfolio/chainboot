1 Endpoints

chainboot reads the blockchain through RPC endpoints, and you bring your own. Free ones take a minute to get (Helius, QuickNode, Alchemy, Triton, Ankr). Add as many as you like: more endpoints mean faster downloads.

2 Systems on chain

Every system below is stored on Solana. Getting one downloads it straight from the chain and checks every file against its hash.

4 Save to chain

Sign in with your wallet and your machines are saved to Solana, encrypted with a key only you can make. Continue on any computer by signing in there. Your wallet signs one message; a small helper account (the vault) then pays the fees of your saves, so you are not asked again.

5 Publish your own system

Any Linux distribution can live on chain. Build a machine the way you like it, then publish it for everyone (or just for yourself).

chainboot run solinux-minimal --name mybox       # install and configure what you need
chainboot export mybox mybox.tar                  # turn the machine into an archive
chainboot keygen me.json                          # your publisher key (fund it with a little SOL)
chainboot publish mybox.tar --name mybox --version 1.0 --reuse solinux-minimal --keypair me.json

Others run it with chainboot run <your-address>/mybox. A root file system archive from any distribution works too.
